# 網站變桌面 App

做好的網站，交給 AI 包一下，就能裝到電腦上，有自己的圖示和獨立視窗。網站之後更新，裝好的 App 會自動換新版。

不用會寫程式，包裝這件事也不用花錢。

## 三步驟

**第 1 步：打開 Claude 桌面版的 Code 分頁**

選 Local，資料夾選你的網站專案。用 Codex 也可以。

**第 2 步：把這段話貼給 AI**

```text
我要把這個網站包成可以裝在電腦上的 App。請先把下面這個 repo 下載到專案外面的暫存資料夾，完整讀過 SETUP.md，不要用網頁摘要，然後一步一步幫我做完：
https://github.com/weifu0716/website-to-desktop-app
需要我登入或點按鈕時，直接告訴我要做什麼。
```

**第 3 步：照 AI 說的做**

它會問你 App 叫什麼名字、有沒有 logo，部署前也會先問過你。做完它會教你怎麼在電腦上按安裝。

## 你要準備

- 一個已經上線、網址是 `https://` 開頭的網站。還沒上線的話，先走 [Firebase 第一次部署懶人包](https://github.com/weifu0716/firebase-first-deploy)
- 網站的原始碼
- 一張 logo，沒有也行，AI 可以用一個字幫你做圖示

## 做完長什麼樣

- 桌面或開始功能表有 App 圖示，也能釘在工作列
- 打開是獨立視窗，沒有網址列
- 斷網時，看過的頁面還打得開
- 你更新網站，使用者不用重裝

## 先知道的限制

- 沒有安裝檔可以傳給別人。對方要裝，就打開你的網站按安裝。
- 要用 Chrome 或 Edge 裝。Mac 的 Safari 也可以。
- 它還是網站，不能自由讀寫電腦裡的檔案，也不能開機自動執行。需要這些功能要改用 Tauri 或 Electron，這包沒有涵蓋。
- 網站用 Wix、Canva 這類平台做的，改不了底層檔案，只能用瀏覽器內建的安裝功能，沒有自動更新和斷網。
